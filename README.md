# CatchUp Landing Page

Standalone mobile-first campus errand landing page.

- `index.html`: responsive page, CSS and touch ripple interactions.
- `catchup-logo.svg`: scalable vector CatchUp-style logo asset.
- `BUSINESS-RESEARCH.md`: business model research, launch strategy, safety, pricing experiments and validation plan.

## Deploy to Vercel
Import this repository as a **new Vercel project**. Select framework preset **Other**, root directory `./`, and no build command. The site is static and does not require Supabase or environment variables.

## Before public launch
Confirm service area, operating hours, pricing, runner availability and policies. Do not make unsupported claims about official campus partnerships, verification, fixed turnaround or university payment integrations.
